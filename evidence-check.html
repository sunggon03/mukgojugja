📚 근거 확인 도우미

AI는 근거 문서 링크만 찾아요. 문서를 열어 문장을 찾는 건 사람이 해요. 그래서 AI가 "읽었다"고 지어내도 앱에 틀린 근거가 들어가지 않아요.

확인할 알레르기·기저질환을 써 주세요 (예: 땅콩, 우유, 새우, 고혈압)
나는 누구? (내 담당만 보여요)
🔒 성곤 검수용 페이지
조원에게 보내지 않는 페이지예요. 결과 모으기·검수 기록은 이 브라우저에만 저장돼요. 검수는 항상 같은 컴퓨터, 같은 브라우저에서 해요.
📊 진행 현황

완료 = 기본 출처 교체(필요한 항목만) + 우선순위 높음 문장 확인. 높음 문장은 조원 결과를 아래 "결과 모으기"에 붙이면 자동으로 줄어요. 이 표는 이 브라우저에만 저장돼서, 결과는 한 사람(김성곤)이 모아요.

결과 모으기

조원이 보낸 제출 내용(// 근거 확인 결과 … 로 시작)을 통째로 붙여 넣어요. 여러 개를 이어 붙여도 돼요.

시트에서 복사해 아래에 붙여도 돼요
📥 조원 결과 모아 보기 · 성곤 검수

"결과 모으기"에 붙인 제출 내용이 모두 여기 쌓여요. 링크를 열어 붙인 문장이 정말 있는지 보고 "검수 OK" 또는 "고치기"를 눌러요. 문장마다 판정, 붙인 원문, 링크, 확인·검수한 사람이 보여요.

done.js 내려받기
🔁 출처 교체가 필요한 항목 표

앱의 기본 설명이 기댄 출처가 약한 항목이에요. 해당 항목을 찾아 기본 설명 문장을 확인하면서 공공기관·학회·최근 논문 자료로 바꿔요. 바꾸면 체크해 두세요. 항목 이름을 누르면 바로 찾아져요.

확인할 문장 고르기

위에서 알레르기·기저질환을 먼저 찾아 주세요.

지금 앱에 들어 있는 문장이에요. 우선순위는 참고용이에요. 꼭 높은 것부터 할 필요는 없고, 이번에 확인할 문장만 체크하세요. 한 번에 10개 안팎을 권해요.

완료 기준: 기본 출처 교체 + 우선순위 높음 문장 확인. 그래서 높음만 보여요. 보통·낮음은 필요할 때만 펼쳐요.
우선순위 기준 · 높음: 아이·나이·교차반응·"쓰지 마세요" 같은 안전 문장, 숫자가 든 문장, 원문을 직접 확인하지 못한 근거, 출처가 약한 기본 설명 · 보통: 대체 재료 설명, 일반 설명 · 낮음: 이미 원문 확인한 문장(10/27), 맛 설명

  3. AI 답변을 통째로 복사해 ③ AI 결과에 붙여요.

        📌 어디까지 복사하나요? (헷갈리면 여기)
        

          
상황이렇게 해요

          
기본 (영어 논문 포함)찾을 단어가 있는 문장을 기준으로 그 문장 + 앞 문장 1개 + 뒤 문장 1개 = 3문장을 그대로 복사해요

          
표 안에 있음그 줄 전체 + 표 제목을 복사해요

          
목록(•, 1. 2.) 안에 있음그 항목 + 목록 바로 위 설명 한 줄을 복사해요

          
어디까지인지 정말 모르겠음그 문단 전체를 복사해요. 많이 복사하는 건 괜찮아요(성곤이 줄여요)

          
단어가 여러 군데 나옴앱 문장과 가장 비슷한 곳 하나만 복사하고, 다른 곳은 "위치" 칸에 적어요
