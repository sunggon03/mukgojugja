① 원본 레시피 찾기② 프롬프트로 AI 변환③ 자동 검사④ 다른 조원이 검수⑤ 코드 복사해 제출

만드는 사람 (제출자)

  1. 아래 표의 사이트에서 많은 사람이 만들어 본 레시피를 찾아요.
  2. 아래 프롬프트를 복사해 ChatGPT·Gemini·Claude 등에 붙여넣어요.
  3. 프롬프트 맨 아래에 레시피 주소와 본문(재료·분량·순서)을 직접 복사해 붙여요.
  4. AI가 준 JSON을 그대로 복사해 ② 자동 검사에 붙여넣어요.

원본은 이런 곳에서만 골라요

많은 사람이 실제로 만들어 보고 맛을 확인한 레시피만 받아요. 개인 블로그·카페·SNS·AI 답변은 받지 않아요.

원본 사이트통과 기준 (검수자가 원본에서 확인)
만개의레시피요리 후기 10개 이상
유튜브 요리 영상조회수 10만 이상
우리의식탁 · 해먹남녀후기·스크랩·좋아요 중 화면에 보이는 숫자 10 이상, 숫자가 안 보이는 전문가 레시피는 메모로 이유 설명. 우리의식탁 "AI 레시피"는 제외
해외 대형 레시피 사이트
Allrecipes, BBC Good Food, America's Test Kitchen 등		리뷰(평점) 50개 이상, 리뷰가 없는 셰프·테스트키친 사이트는 메모로 이유 설명

다른 사이트를 쓰고 싶으면 먼저 김성곤에게 물어봐 주세요.

자주 하는 실수 8가지

  1. 주소만 주기 → AI가 재료를 지어냄. 본문을 꼭 붙여넣기
  2. 몇 인분인지 빼먹기 → 원본 4인분 분량이 1인분으로 들어감
  3. 양념장 재료 빠뜨리기 → "양념: …" 줄도 모두 복사
  4. AI 답변 중 일부만 복사 → 코드블록 전체(또는 답변 통째)를 붙여넣기
  5. 프롬프트를 ②에 붙이기 → ②에는 AI의 답변을 붙이기
  6. 개인 블로그·카페·인스타 레시피 쓰기 → 검증이 안 돼서 받지 않아요. 위 표의 사이트에서 고르기
  7. AI에게 레시피를 만들어 달라고 하기 → AI가 만든 레시피는 받지 않아요. 사람이 쓴 레시피를 옮기기만 해요
  8. 제출 코드를 손으로 고치기 → 고칠 게 있으면 ②부터 다시. 고친 코드는 검사코드가 안 맞아요
⚠️ 주소만 주고 "이 레시피 바꿔줘"라고 하면 안 돼요. 많은 AI가 링크를 실제로 열지 못하고 재료를 그럴듯하게 지어내요. 본문을 직접 붙여넣어야 원본과 대조할 수 있어요.

검수 요청 주고받기

    
제출자와 검수자는 보통 다른 기기를 써요. 제출자는 ②에서 오류 없는 레시피를 만들고 이름을 쓴 뒤 검수 요청을 복사해 검수자에게 보내요. 검수자는 받은 요청을 아래에 붙이면 같은 레시피가 열려요.
